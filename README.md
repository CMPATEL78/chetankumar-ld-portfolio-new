# Dr. Chetankumar Patel — L&D & Instructional Design Portfolio

## Rebuilt six-case portfolio

This package consolidates the six existing case-study ZIP resources into one GitHub Pages-ready site.

### Structure
- `index.html` — main portfolio homepage
- `styles.css` — homepage styling
- `case-studies/case-01/` — Product Design & Development
- `case-studies/case-02/` — Manufacturing Learning & Qualification
- `case-studies/case-03/` — AI Capability Development, including the complete multi-page learning-design journey
- `case-studies/case-04/` — Experiential & Values-Based Learning
- `case-studies/case-05/` — Curriculum, Course & Content Design
- `case-studies/case-06/` — Professional & Leadership Capability Development

### Important
The case-study pages retain their supplied content and supporting artefacts. Relative links were checked across the complete site; no broken local HTML links remain.

### GitHub Pages deployment
Upload the contents of this package to the root of the GitHub repository used for the portfolio. Replace the existing `index.html`, `styles.css`, and `case-studies` folder with the corresponding files from this package.

Do not rename the case-study folders or files after uploading, because the internal links use these relative paths.
